# B. Ayush Gowda Website

A mobile-first static achievement portfolio.

## Files
- index.html — website
- style.css — design and responsive layout
- script.js — mobile navigation

## Add real photos
The Gallery section currently contains placeholders. Replace the `.photo` blocks in `index.html` with `<img>` elements or set background images in CSS.

## Publish for free
Upload all three files to GitHub Pages, Netlify, Cloudflare Pages, or another static hosting service.
